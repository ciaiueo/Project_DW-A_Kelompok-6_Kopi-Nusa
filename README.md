# ☕ KOPI NUSA
### Teman Ngopi di Setiap Cerita

Website profil UMKM minuman yang dibuat sebagai project kelompok mata kuliah **Desain Web**. Website ini dirancang untuk memperkenalkan Kopi Nusa, menampilkan pilihan produk, dan memberikan informasi harga menu dengan tampilan yang menarik serta mudah dipahami.

---

## 📌 1. Deskripsi Project

**Kopi Nusa** merupakan konsep website UMKM di bidang minuman yang menyediakan berbagai pilihan kopi dan minuman non-kopi. Website ini dibuat menggunakan HTML5 dan CSS3 sebagai penerapan materi yang telah dipelajari selama perkuliahan.

Website ini memiliki empat halaman utama, yaitu Beranda, Profil, Galeri, dan Menu. Setiap halaman mempunyai fungsi yang berbeda, tetapi saling terhubung melalui navigasi agar pengunjung dapat mengakses informasi dengan mudah.

Desain website menggunakan nuansa warna yang terinspirasi dari kopi, dengan kombinasi warna cokelat dan cream untuk memberikan kesan hangat, nyaman, dan sesuai dengan identitas Kopi Nusa.

**Tagline:** *Teman Ngopi di Setiap Cerita*

**Tema project:** UMKM / Produk Lokal

## 🎯 2. Tujuan Pembuatan

Tujuan pembuatan website Kopi Nusa adalah:

- Menerapkan HTML5 dan CSS3 dalam pembuatan website.
- Membuat website profil UMKM yang memiliki struktur halaman yang jelas.
- Menampilkan informasi usaha dan produk secara terorganisasi.
- Menyediakan galeri produk beserta nama dan harga menu.
- Menerapkan navigasi yang menghubungkan setiap halaman.
- Mengatur tampilan website agar dapat menyesuaikan ukuran layar perangkat.
- Melatih kemampuan menyusun struktur HTML, mengatur tampilan CSS, dan mengelola aset website.

## ✨ 3. Fitur Website

### A. Beranda (`index.html`)

Beranda merupakan halaman utama yang pertama kali dilihat pengunjung. Halaman ini menampilkan identitas Kopi Nusa, tagline, gambar utama, informasi singkat tentang usaha, dan beberapa produk pilihan.

Halaman Beranda dibuat untuk memberikan gambaran awal mengenai Kopi Nusa dan memudahkan pengunjung menemukan halaman lainnya melalui navigasi.

### B. Profil (`profil.html`)

Halaman Profil berisi informasi mengenai usaha Kopi Nusa. Halaman ini membantu pengunjung mengenal konsep usaha dan informasi pendukung yang berkaitan dengan identitas UMKM.

### C. Galeri (`galeri.html`)

Halaman Galeri menampilkan koleksi produk Kopi Nusa berdasarkan kategori. Setiap produk disajikan menggunakan gambar dan informasi produk agar pengunjung dapat melihat pilihan minuman dengan lebih mudah.

Terdapat lima kategori produk:

- **Coffee** — berbagai pilihan minuman kopi.
- **Frappe** — minuman frappe dengan beragam rasa.
- **Milk Tea** — minuman teh susu dengan beberapa varian.
- **Chocolate** — pilihan minuman berbahan cokelat.
- **Tea** — minuman teh dengan variasi rasa buah.

Secara keseluruhan, Galeri menampilkan 22 pilihan menu.

### D. Menu (`data.html`)

Halaman Menu menampilkan daftar produk beserta harga dalam bentuk tabel. Halaman ini membantu pengunjung melihat informasi nama menu dan harga secara lebih terstruktur.

Galeri berfokus pada tampilan visual produk, sedangkan halaman Menu berfokus pada penyajian data produk dan harga.

## 🛠️ 5. Teknologi yang Digunakan

### HTML5

HTML5 digunakan untuk menyusun struktur dan konten halaman website, antara lain:

- Heading dan paragraf.
- Daftar atau list.
- Gambar beserta atribut `alt`.
- Hyperlink untuk navigasi ant halaman.
- Tabel untuk menampilkan data menu dan harga.
- Elemen semantik HTML untuk menyusun bagian halaman.

### CSS3

CSS3 digunakan untuk mengatur tampilan dan tata letak website, antara lain:

- Pengaturan warna dan tipografi.
- Pengaturan margin, padding, dan border melalui box model.
- Flexbox untuk membantu menyusun elemen halaman.
- Styling navigasi, kartu produk, dan tabel.
- Pengaturan tampilan melalui media query.
- Penyesuaian tata letak untuk berbagai ukuran layar.

### Tools yang Digunakan

- **Visual Studio Code** — untuk menulis dan mengelola kode HTML serta CSS.
- **Web Browser** — untuk menjalankan dan menguji tampilan website.
- **Git dan GitHub** — untuk mengelola versi kode dan menyimpan project secara online.

Project dibuat menggunakan HTML5 dan CSS3 tanpa framework CSS seperti Bootstrap atau Tailwind CSS dan tanpa JavaScript.

## 📱 6. Responsive Design

Website Kopi Nusa dirancang agar tampilannya dapat menyesuaikan ukuran layar perangkat.

Pengaturan responsive dilakukan menggunakan CSS dan media query. Penyesuaian tampilan bertujuan agar konten tetap mudah dibaca, gambar berada dalam area yang sesuai, dan navigasi tetap dapat digunakan.

Pengujian tampilan dilakukan dengan membandingkan hasil pada ukuran layar desktop dan mobile. Pengujian pada tablet juga dapat dilakukan untuk memeriksa tampilan pada ukuran layar menengah.

## 🚀 9. Cara Menjalankan Website

Website dapat dijalankan secara lokal melalui browser.

Langkah-langkah:

1. Download atau clone repository Kopi Nusa dari GitHub.
2. Ekstrak file ZIP apabila project diunduh dalam bentuk ZIP.
3. Buka folder `kopi nusa` menggunakan Visual Studio Code.
4. Pastikan file HTML, stylesheet, dan folder gambar berada pada lokasi yang sesuai.
5. Buka file `index.html` menggunakan browser.
6. Gunakan menu navigasi untuk berpindah ke halaman Profil, Galeri, dan Menu.

Website menggunakan HTML dan CSS sehingga dapat dijalankan secara lokal tanpa server backend.

Jika ingin menggunakan Live Server di Visual Studio Code, buka `index.html`, lalu pilih **Open with Live Server** jika ekstensi tersebut telah terpasang.
