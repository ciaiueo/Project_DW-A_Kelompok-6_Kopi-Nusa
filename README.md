### Teman Ngopi di Setiap Cerita

Website Kopi Nusa merupakan proyek desain web yang mengangkat tema **UMKM dan Produk Lokal**, khususnya usaha minuman kopi dan minuman kekinian. Website ini dirancang sebagai media informasi untuk memperkenalkan identitas usaha, menampilkan pilihan produk, serta memberikan informasi nama menu, kategori, dan harga kepada pengunjung.

Tampilan website menggunakan perpaduan warna bernuansa kopi dengan desain yang sederhana, nyaman dilihat, dan mudah digunakan. Website terdiri dari empat halaman utama yang saling terhubung melalui navigasi.

## 🏪 Deskripsi Website

Kopi Nusa merupakan konsep UMKM minuman yang menawarkan beragam pilihan minuman berbahan dasar kopi maupun non-kopi. Website ini dibuat untuk memberikan gambaran mengenai identitas usaha, nilai yang ingin disampaikan, dan pilihan produk yang tersedia.

Melalui website ini, pengunjung dapat mengenal Kopi Nusa melalui halaman Beranda dan Profil, melihat tampilan produk melalui halaman Galeri, serta mengetahui daftar menu dan harga melalui halaman Menu.

Desain website menggunakan nuansa warna krem dan cokelat yang terinspirasi dari warna kopi. Susunan konten dibuat agar informasi usaha dan produk dapat ditemukan dengan mudah, baik ketika website dibuka melalui komputer maupun perangkat seluler.

**Catatan:** Kopi Nusa digunakan sebagai konsep usaha untuk keperluan proyek desain web.

## 🖥️ Fitur dan Halaman Website

Website Kopi Nusa terdiri dari empat halaman utama.

### 1. Beranda — `index.html`

Halaman Beranda merupakan halaman awal yang memberikan gambaran umum tentang Kopi Nusa.

Konten yang tersedia meliputi:

- Header dan navigasi utama.
- Bagian hero berisi tagline dan pengenalan singkat.
- Gambar utama yang menggambarkan suasana atau produk Kopi Nusa.
- Bagian menu favorit yang menampilkan beberapa produk pilihan.
- Bagian pengenalan singkat mengenai usaha.
- Tombol untuk menuju halaman Menu dan Profil.
- Footer yang berisi informasi singkat website.

Halaman ini dirancang untuk menarik perhatian pengunjung dan membantu mereka menemukan informasi yang dibutuhkan.

### 2. Profil — `profil.html`

Halaman Profil berisi informasi yang lebih lengkap mengenai konsep dan identitas Kopi Nusa.

Kontennya mencakup pengenalan usaha, cerita atau latar belakang konsep, nilai yang ingin dibawa, serta informasi mengenai visi dan misi sesuai isi halaman.

Halaman ini membantu pengunjung memahami konsep Kopi Nusa dan alasan usaha ini menghadirkan berbagai pilihan minuman.

### 3. Galeri — `galeri.html`

Halaman Galeri digunakan untuk menampilkan katalog visual produk Kopi Nusa.

Produk dikelompokkan menjadi lima kategori:

- Coffee
- Frappe
- Milk Tea
- Chocolate
- Tea

Setiap produk ditampilkan dalam bentuk kartu yang berisi gambar, nama produk, dan informasi pendukung sesuai konten yang tersedia. Pengelompokan ini membantu pengunjung melihat pilihan minuman berdasarkan kategori.

### 4. Menu — `data.html`

Halaman Menu menampilkan daftar lengkap produk dalam bentuk tabel.

Tabel berisi lima kolom, yaitu:

- Nomor produk.
- Nama menu.
- Kategori.
- Ukuran.
- Harga.

Halaman ini memuat 22 pilihan minuman. Seluruh produk menggunakan satu ukuran, yaitu Regular, dengan harga yang berbeda sesuai jenis minuman.

Pada bagian akhir halaman terdapat informasi pemesanan dan tautan menuju Instagram Kopi Nusa.

**Navigasi:** keempat halaman dihubungkan melalui menu Beranda, Profil, Galeri, dan Menu sehingga pengunjung dapat berpindah halaman dengan mudah.

## 🛠️ Teknologi yang Digunakan

### HTML5

HTML5 digunakan untuk menyusun struktur dan konten halaman website. Elemen yang digunakan antara lain:

- `header` untuk bagian kepala website.
- `nav` untuk navigasi ant halaman.
- `main` untuk konten utama.
- `section` untuk mengelompokkan bagian konten.
- `footer` untuk bagian bawah halaman.
- `table`, `thead`, `tbody`, `tr`, `th`, dan `td` untuk menyusun tabel daftar menu.
- `img` untuk menampilkan gambar produk.
- `a` untuk membuat tautan dan navigasi.

### CSS3

CSS3 digunakan untuk mengatur tampilan visual website, meliputi:

- Warna dan latar belakang.
- Tipografi dan ukuran teks.
- Jarak, margin, dan padding.
- Tata letak menggunakan Flexbox dan teknik layout CSS lain sesuai kebutuhan.
- Desain kartu produk.
- Tampilan tabel.
- Efek visual pada tombol dan tautan.
- Media query untuk menyesuaikan tampilan pada berbagai ukuran layar.

Website dibuat menggunakan HTML5 dan CSS3 tanpa framework CSS siap pakai, JavaScript, maupun CMS.

### Google Fonts

Jika diaktifkan dalam file CSS, Google Fonts digunakan untuk membantu membangun karakter visual teks. Penggunaan font dari layanan tersebut membutuhkan koneksi internet, kecuali font telah disediakan secara lokal.

## 🚀 Cara Menjalankan Website

Website ini merupakan website statis yang menggunakan HTML dan CSS. Oleh karena itu, website dapat dibuka langsung melalui browser tanpa menjalankan server backend atau database.

### Langkah 1 — Siapkan folder proyek

Pastikan seluruh file HTML, CSS, gambar, dan README berada dalam folder proyek yang sama sesuai struktur folder.

### Langkah 2 — Buka melalui Visual Studio Code

1. Jalankan Visual Studio Code.
2. Pilih **File → Open Folder**.
3. Pilih folder `kopi nusa`.
4. Pastikan file `index.html`, `profil.html`, `galeri.html`, `data.html`, dan folder `assets` terlihat di Explorer.

### Langkah 3 — Jalankan halaman website

1. Buka file `index.html`.
2. Klik kanan pada file tersebut.
3. Pilih **Open with Live Server** jika ekstensi Live Server telah terpasang.

Jika Live Server tidak digunakan, buka file `index.html` langsung melalui browser. Karena website bersifat statis, cara tersebut dapat digunakan untuk melihat hasilnya.

### Langkah 4 — Coba navigasi

Klik setiap menu pada header:

- Beranda
- Profil
- Galeri
- Menu

Pastikan setiap tautan membuka halaman yang benar.

### Langkah 5 — Periksa gambar

Periksa apakah seluruh gambar tampil dengan benar. Jika gambar tidak muncul, periksa:

- Nama file gambar.
- Huruf besar dan kecil pada nama file.
- Ekstensi gambar, seperti `.jpg`, `.jpeg`, atau `.png`.
- Lokasi gambar dalam folder `assets/images/`.
- Kesesuaian alamat gambar pada atribut `src`.

### Langkah 6 — Uji tampilan mobile

Buka Developer Tools pada browser dengan `Ctrl + Shift + I`, lalu aktifkan Device Toolbar dengan `Ctrl + Shift + M`.

Pilih ukuran perangkat seluler dan periksa apakah navigasi, teks, gambar, kartu produk, serta tabel tetap dapat digunakan dengan nyaman.

## 📱 Desain Responsif

Website dirancang agar dapat menyesuaikan tampilan dengan ukuran layar yang berbeda.

### Desktop

Pada layar desktop, konten memiliki ruang yang lebih luas untuk menampilkan gambar, teks, kartu produk, dan tabel menu.

### Tablet

Pada layar tablet, susunan konten dapat menyesuaikan ruang yang tersedia agar elemen tidak saling bertumpuk.

### Mobile

Pada layar ponsel, tata letak perlu menyesuaikan lebar layar agar teks tetap terbaca dan gambar tidak keluar dari area konten. Tabel menu dapat menggunakan pembungkus dengan pengguliran horizontal jika lebar tabel melebihi layar.

Pengujian dilakukan melalui browser menggunakan mode perangkat. Hasil akhir tetap perlu diperiksa pada ukuran layar yang digunakan untuk dokumentasi screenshot.

## 🖼️ Sumber Gambar dan Referensi

Website menggunakan gambar untuk memperkuat tampilan katalog produk dan pengenalan usaha.

Gambar disimpan pada folder `assets/images/` dan dipanggil melalui atribut `src` pada elemen HTML. Setiap gambar sebaiknya memiliki atribut `alt` yang menjelaskan isi gambar agar lebih mudah dipahami ketika gambar tidak dapat ditampilkan dan mendukung aksesibilitas.

**Sumber gambar:** cantumkan tautan sumber asli dari setiap gambar yang benar-benar digunakan dalam proyek. Pastikan sumber yang ditulis sesuai dengan gambar pada folder proyek, bukan sekadar situs tempat mencari gambar.

Format pencatatan yang dapat digunakan:

| No. | Nama File | Sumber Gambar |
|---:|---|---|
| 1 | `hero.jpg` | Isi dengan URL sumber asli |
| 2 | `kopi-nusa-aren.jpg` | Isi dengan URL sumber asli |
| 3 | `nusa-latte.jpg` | Isi dengan URL sumber asli |
| 4 | Gambar produk lainnya | Isi dengan URL sumber asli |

Jika gambar dibuat sendiri, tuliskan bahwa gambar merupakan dokumentasi atau aset buatan kelompok. Jika gambar diperoleh dari situs penyedia gambar, cantumkan nama situs dan tautan gambar sesuai sumber yang digunakan serta perhatikan ketentuan lisensinya.
