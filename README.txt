2. DESKRIPSI WEBSITE
Kopi Nusa adalah website UMKM minuman kekinian yang kami
buat untuk tugas Project Kelompok Desain Web.
Website ini berisi informasi tentang Kopi Nusa, profil,
galeri produk, dan daftar menu beserta harga.
Menu yang tersedia terdiri dari beberapa kategori, yaitu
Coffee, Frappe, Milk Tea, Chocolate, dan Tea.
Konsep desain dibuat dengan warna yang dominan cokelat dan
cream supaya sesuai dengan tema kopi dan minuman.

3. HALAMAN WEBSITE
Website Kopi Nusa terdiri dari 4 halaman, yaitu:
1. index.html
   Berisi halaman utama atau Beranda. Pada halaman ini
   terdapat nama Kopi Nusa, tagline, gambar utama, beberapa
   menu favorit, dan informasi singkat tentang Kopi Nusa.
2. profil.html
   Berisi informasi mengenai Kopi Nusa, seperti profil,
   visi, misi, dan keunggulan.
3. galeri.html
   Berisi tampilan produk Kopi Nusa dalam bentuk card.
   Produk ditampilkan menggunakan gambar, nama, deskripsi
   singkat, dan harga. Menu dibagi berdasarkan kategorinya.
4. data.html
   Berisi daftar menu dalam bentuk tabel. Data yang
   ditampilkan yaitu nomor, nama menu, kategori, ukuran,
   dan harga.

4. TEKNOLOGI YANG DIGUNAKAN
Dalam pembuatan website ini kami menggunakan:
- HTML5
- CSS3

Website dibuat menggunakan HTML dan CSS tanpa menggunakan
Bootstrap, Tailwind, JavaScript, CMS, ataupun template

8. CARA MENJALANKAN WEBSITE
Cara menjalankan website cukup dengan membuka file
index.html.
Langkah-langkah:
1. Buka folder Kopi-Nusa di Visual Studio Code.
2. Pastikan semua file dan folder masih berada di tempatnya.
3. Buka file index.html.
4. Klik kanan pada index.html.
5. Pilih "Open with Live Server".
6. Website akan terbuka di browser.
Website juga bisa dibuka langsung dengan klik dua kali
index.html, tetapi penggunaan Live Server lebih memudahkan
saat melakukan pengecekan.
